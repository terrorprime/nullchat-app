How would you like to use NullChat?

⚠

Can’t connect

NullChat couldn’t reach its server. Check your internet connection, then try again.

Recommended

Use your NullChat server

Sign in with the account you already made in your browser. Your accounts, servers and messages live on , so this is the one to pick if you want the same account here.

🖥

Host on this computer

Run your own NullChat server right here. Your accounts and messages are saved on this PC, and friends on your network can join from their browser or the NullChat app. It starts with no accounts, so accounts you made on an online server won’t exist here.

🌐

Join a server

Connect to a NullChat server someone else is running — on the internet or on your local network.

You can switch servers any time from File → Switch Server.
